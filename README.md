# Sales Analysis Dashboard 📊

An interactive **Power BI** dashboard that analyzes sales performance across channels, geography, products, and customer segments — built to surface actionable business insights through dynamic, multi-level filtering.

![Sales Analysis Dashboard](Sales%20Analsis%20.png)

## Overview

This dashboard provides a 360° view of sales performance, allowing stakeholders to drill down by **Manager**, **Employee**, **Product Category**, and **City** to explore trends and identify opportunities across the business.

## Key Features

- **Multi-level Filtering** — Slicers for Manager Name, Employee Name, Product Category, and City enable granular, on-demand analysis
- **Sales by Channel** — Breakdown of Online vs. In-Store sales performance
- **Sales by Month** — Trend line tracking monthly sales performance across the full year
- **Geographic Analysis** — Interactive map view showing sales distribution by city
- **Customer Segmentation** — Visual breakdown by gender, customer type (Loyal / Retail / New), and satisfaction level
- **Product Performance** — Ranked view of top-performing products
- **Top Customers** — Ranked view of highest-value customers by sales

## Dashboard Highlights

| Metric | Insight |
|---|---|
| Sales Channel | Online sales significantly outperform in-store sales |
| Customer Base | Majority of customers report "High" or "Very High" satisfaction |
| Customer Mix | Nearly half of sales come from Retail customers, followed by Loyal and New customers |
| Seasonality | Sales peak mid-year (July) before tapering into Q4 |

## Tools & Technologies

- **Power BI Desktop** — Data modeling, DAX measures, and dashboard design
- **Interactive Visuals** — Donut charts, area/trend charts, bar charts, and map visualizations

## Files

- `sales analysis overview.pbix` — Full Power BI project file (open in Power BI Desktop)
- `Sales Analsis .png` — Dashboard preview image

## How to Use

1. Download `sales analysis overview.pbix`
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
3. Use the slicers at the top to filter by Manager, Employee, Product Category, or City
4. Explore the visuals to analyze sales trends, customer behavior, and product performance
